# E-commerce Sales Analysis using Excel

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to identify trends, regional performance, category distribution, and revenue patterns.

## Objective
To evaluate monthly sales performance, regional contribution, and product category distribution using data-driven analysis.

## Tools & Techniques Used
- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Bar Charts
- Histogram (Frequency Distribution)
- Comparative Analysis

## Analysis Performed
- Monthly Sales & Profit Comparison
- Region-wise Sales Breakdown
- Category-wise Performance Analysis
- Sales Distribution using Histogram

## Key Insights
- Identified high-performing months
- Evaluated region contribution to total sales
- Analyzed product category distribution
- Observed sales frequency patterns
